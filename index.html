Plataforma de Gestão Interna — Cruz Vermelha Portuguesa

A delegação de Gandarela precisava de um sistema para gerir clientes, marcações e as horas dos funcionários. Desenvolvi a plataforma de raiz, do modelo da base de dados à interface.

  • Base de dados relacional em MySQL para clientes, marcações e registo de horas.
  • API REST em Node.js e Express.js.
  • Autenticação com JWT, palavras-passe cifradas com bcrypt e perfis Administrador/Staff controlados por middleware.
  • Calendário interativo com FullCalendar para as marcações diárias.
Node.js Express.js MySQL JWT bcrypt FullCalendar
