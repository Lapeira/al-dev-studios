# CV em PDF

`cv-programador.html` é a fonte do ficheiro `Alexandre-Sousa-CV-Programador.pdf` (na pasta principal do portfolio).

Para atualizar o CV:

1. Edita o texto em `cv-programador.html`.
2. Abre o ficheiro no Microsoft Edge.
3. Carrega em **Ctrl+P** e escolhe:
   - Impressora: **Guardar como PDF**
   - Esquema: **Vertical**, papel **A4**
   - Margens: **Nenhuma**
   - Em "Mais definições", desliga **Cabeçalhos e rodapés**
4. Guarda por cima de `Alexandre-Sousa-CV-Programador.pdf`.
5. Confirma que tem **uma página** e que os links funcionam.
